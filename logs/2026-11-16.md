### 💡 学びのポイント
**新規習得：**
- `document.createElement()` で要素を作り、`appendChild()` で DOM に追加する流れ
- `addEventListener("click", fn)` には関数そのものを渡す（`fn()` と書くと即実行されてしまう）
- `querySelectorAll()` は静的な `NodeList` を返すので、`for...of` で1つずつ処理できる

**理解深化：**
- 静的サイト（HTML/CSS/JS のみ）では `npm run dev` は動かない。`package.json` が無ければ npm スクリプト自体が存在しない
- 表示確認だけなら `file://` で直接開くか、`python3 -m http.server` や `npx serve` で十分
- インライン `<script>` は、その位置までに解析済みの DOM しか参照できない

**トラブルシューティング：**
- `npm run dev` が失敗：`~/dev/odin-notes` に `package.json` が無かった。`python3 -m http.server 8000` に切り替えて解決
- クリックしても何も起きない：元々あった `<button>` を消したため `querySelectorAll("button")` が空になり、リスナーが1つも登録されていなかった。`<button>` を戻す必要がある

### 🔗 実装コード
- リポジトリ：[LJDJGC/odin-notes](https://github.com/LJDJGC/odin-notes)
- 主要コード：
```tsx
function createParagraph() {
  const para = document.createElement("p");
  para.textContent = "ボタンが押されました";
  document.body.appendChild(para);
}

const buttons = document.querySelectorAll("button");

for (const button of buttons) {
  button.addEventListener("click", createParagraph);
}
```
