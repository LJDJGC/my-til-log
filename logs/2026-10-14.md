- `TYPE_COLORS[dominantType] || DEFAULT_COLORS` — 「その日の主役（dominantType）の色」でセルを塗り、データが無い日は `dominantType === ""`（falsy）なので灰色にフォールバックする。空文字が falsy であることが機能の前提
- 月ラベルの `marginTop: index === 0 ? 0 : 14` はグリッドセル高さ(12px)＋gap(4px)＝16px にラベルを合わせる位置調整ハック
- サマリーは `dayMap.values()` を `reduce` し、`byType["study"]` / `byType["workout"]` を合計するだけの純粋な集計

**理解深化：**
- モジュール末尾に定義した `dateKey` が先に使う側の JSX から見えても動くのは、import 時（モジュール評価時）ではなく React レンダー時に実行されるため
- `tsc --noEmit` と `eslint` を個別に回すと、既存のバグ（`page.tsx:37` の effect 内 `setLoading`）と今回の変更を切り分けられる

                    className={`h-3 w-3 rounded-sm ${colors[level]} ${isToday ? "ring-2 ring-blue-400" : ""}`}
                />
            );
        })}

- `TYPE_COLORS[dominantType] || DEFAULT_COLORS` — cells are colored by the day's dominant type; days with no data have `dominantType === ""` (falsy), falling back to gray. The empty-string-is-falsy behavior is the key premise
- Month label `marginTop: index === 0 ? 0 : 14` is a positioning hack to align labels with the grid cell height (12px) + gap (4px)
- Summary is a pure aggregation: `reduce` over `dayMap.values()` summing `byType["study"]` / `byType["workout"]`

**Deeper Understanding:**
- `dateKey` defined at the bottom of the module works when used in JSX above because it runs at React render time, not at module evaluation (import) time
- Running `tsc --noEmit` and `eslint` separately helps isolate existing bugs from regressions caused by new changes

**Troubleshooting:**
