### 💡 学びのポイント
**新規習得：**
- `<script>` に `defer` を付けると HTML の解析が終わってから実行されるので、`<head>` に置いても DOM 要素を確実に取得できる（`type="module"` も同様に遅延実行される）
- `<link rel="icon" href="data:,">` を入れると、ブラウザが自動で探す `favicon.ico` の 404 を消せる
- `npx http-server -c-1` の `-c-1` はキャッシュ無効。`-o` でブラウザを自動起動、`-p` でポート指定ができる

**理解深化：**
- `type="mojule"` は `module` のタイポで、ブラウザが JS として実行してくれない。綴りミスだとエラーというより「何も起きない」現象になる
- `src` のファイル名違い（`script.js` と `javascript.js`）は 404 になる。Console の 404 は favicon だけでなくスクリプト自体の可能性も疑う
- `document,querySelectorAll(...)` のカンマはカンマ演算子になり、グローバルな `querySelectorAll` を呼ぼうとして `ReferenceError` になる。ドットとの違いを意識する
- 進みが遅く感じる日でも、エラーを1つずつ潰していけば確実に前に進めると実感できた

**トラブルシューティング：**
- ボタンを押しても無反応：原因は `type="mojule"` のタイポ、`src="script.js"` のファイル名違い、`document,querySelectorAll` のカンマの3つが重なっていた。それぞれ修正して解決
- `/favicon.ico` の 404：アイコンファイルが無いだけなので `<link rel="icon" href="data:,">` を追加して解消
- `This page uses Chrome's Built-In AI features (LanguageDetector)!` は Chrome 側の情報ログで、自作コードのエラーではないと切り分け

### 🔗 実装コード
- リポジトリ：[LJDJGC/odin-notes](https://github.com/LJDJGC/odin-notes)
- 主要コード：
```tsx
// index.html
<button>Player 1: Chris</button>
<script defer src="javascript.js"></script>

// javascript.js
function createParagraph() {
  const para = document.createElement("p");
  para.textContent = "ボタンは押されました！";
  document.body.appendChild(para);
}

const buttons = document.querySelectorAll("button");

for (const button of buttons) {
  button.addEventListener("click", createParagraph);
}
```
