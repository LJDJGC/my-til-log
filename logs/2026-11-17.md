### 💡 学びのポイント
**新規習得：**
- `<script>` に `defer` を付けると HTML の解析が終わってから実行されるので、`<head>` に置いても DOM 要素を確実に取得できる（`type="module"` も同様に遅延実行される）
- `<link rel="icon" href="data:,">` を入れると、ブラウザが自動で探す `favicon.ico` の 404 を消せる
- `npx http-server -c-1` の `-c-1` はキャッシュ無効。`-o` でブラウザを自動起動、`-p` でポート指定ができる

**理解深化：**
- `type="mojule"` は `module` のタイポで、ブラウザが JS として実行してくれない。綴りミスだとエラーというより「何も起きない」現象になる
- `src` のファイル名違い（`script.js` と `javascript.js`）は 404 になる。Console の 404 は favicon だけでなくスクリプト自体の可能性も疑う
- `document,querySelectorAll(...)` のカンマはカンマ演算子になり、グローバルな `querySelectorAll` を呼ぼうとして `ReferenceError` になる。ドットとの違いを意識する
- 進みが遅く感じる日でも、エラーを1つずつ潰していけば確実に前に進めると実感できた

**トラブルシューティング：**
- ボタンを押しても無反応：原因は `type="mojule"` のタイポ、`src="script.js"` のファイル名違い、`document,querySelectorAll` のカンマの3つが重なっていた。それぞれ修正して解決
- `/favicon.ico` の 404：アイコンファイルが無いだけなので `<link rel="icon" href="data:,">` を追加して解消
- `This page uses Chrome's Built-In AI features (LanguageDetector)!` は Chrome 側の情報ログで、自作コードのエラーではないと切り分け

### 💡 Key Learnings
**Newly Acquired:**
- Adding `defer` to a `<script>` makes it run after the HTML has been parsed, so DOM elements can be found reliably even if the tag is in `<head>` (`type="module"` is deferred by default as well)
- Adding `<link rel="icon" href="data:,">` suppresses the 404 for `favicon.ico` that the browser requests automatically
- With `npx http-server`, `-c-1` disables caching, `-o` opens the browser automatically, and `-p` sets the port

**Deeper Understanding:**
- `type="mojule"` is a typo for `module`, so the browser never executes the JS. A spelling mistake like this shows up as "nothing happens" rather than an obvious error
- A wrong filename in `src` (`script.js` vs `javascript.js`) causes a 404. When the Console shows a 404, it is worth suspecting the script itself, not just the favicon
- `document,querySelectorAll(...)` uses the comma operator and tries to call a global `querySelectorAll`, resulting in a `ReferenceError`. It is important to notice the difference from a dot
- Even on days when progress feels slow, working through errors one by one does move things forward — I could feel that today

**Troubleshooting:**
- Clicking the button did nothing: three problems were stacked up — the `type="mojule"` typo, the wrong `src="script.js"` filename, and the comma in `document,querySelectorAll`. Fixing each one solved it
- `/favicon.ico` 404: there was simply no icon file, so adding `<link rel="icon" href="data:,">` cleared it
- `This page uses Chrome's Built-In AI features (LanguageDetector)!` is an informational log from Chrome, not an error in my own code
