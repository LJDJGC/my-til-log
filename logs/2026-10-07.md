### 💡 学びのポイント
**新規習得：**
- `export default` は「このファイルから外部に公開する1つ目のもの」を指定。`page.tsx` が `import GrassCalendar from ...` で使えるのはこのため
- props の分解代入 `({ sessions, weeks = 12 }: Props)` — `weeks = 12` はデフォルト値

**理解深化：**
- props にも state にも依存しない定数は**モジュールレベル**に置く。コンポーネント内だと毎レンダリングで作り直される
- `DEFAULT_COLORS` は neutral gray にする理由：green は workout 専用色なので、gray と区別しないと「データなしの日」と「筋トレの日」が視覚的に混同される

**トラブルシューティング：**
- `DEFAULT_COLORS` を移動する際に空の `export default function` を新規作成 → 二重宣言エラー（`TS2393`）。移動時は「元を消してから移す」順序が大事

### 💡 Key Learnings
**Newly Acquired:**
- `export default` specifies the file's primary export — this is why `page.tsx` can `import GrassCalendar from ...`
- Destructured props with defaults: `({ sessions, weeks = 12 }: Props)` — `weeks = 12` is the fallback value

**Deeper Understanding:**
- Constants not dependent on props/state belong at **module level** — inside the component they'd be recreated every render
- `DEFAULT_COLORS` should be neutral gray because green is workout's color — mixing them would blur "no data day" vs "workout day"

**Troubleshooting:**
- When moving `DEFAULT_COLORS`, accidentally created an empty `export default function` → duplicate declaration (`TS2393`). Order matters: delete old first, then move
