**Deeper Understanding:**
- "Committed" and "pushed" are two different things. The `## main...origin/main` line in `git status` tells you whether anything has not been pushed yet
- Error messages usually state the cause directly (`pathspec ... did not match` = that file does not exist)
- Rather than anxiously adding more reading, putting today's work into words makes the understanding stick better

**Troubleshooting:**
- `git add README.md` → `fatal: pathspec 'README.md' did not match any files`: I hadn't created README.md yet
