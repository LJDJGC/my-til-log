### 💡 学びのポイント
**新規習得：**
- `git init` と `git commit` はローカル完結。GitHub に反映するには `git remote add` と `git push` が必須
- `git remote -v` で送り先が登録されているか確認できる
- `git push -u origin main` の `-u` は初回だけ付ければよい（以降は `git push` だけでOK）

**理解深化：**
- 「コミットした」と「push した」は別物。`git status` の `## main...origin/main` 表示で未pushかどうか判断できる
- エラーメッセージは基本的にそのまま原因を言っている（`pathspec ... did not match` = そのファイルが存在しない）
- 焦って読む学習を増やすより、今日やった作業を言葉にして残すほうが理解が定着する

**トラブルシューティング：**
- `git add README.md` → `fatal: pathspec 'README.md' did not match any files`：README.md をまだ作成していなかった
- `git commit` → `nothing added to commit`：ステージに何も乗っていない状態でコミットしようとしていた
- ファイルが GitHub に表示されない：リモート未設定で push していなかった。`git remote add origin <URL>` → `git push -u origin main` で解決
- 読む学習（The Odin Project の読み物）は今日も進まなかった。焦りはあるが、Git の実作業をアウトプットできたのでゼロではない

### 🔗 実装コード

- 主要コード：
```bash
# ローカルにあるプロジェクトをGitHubへ上げる流れ
git init
git add .
git commit -m "first commit"
git remote add origin git@github.com:LJDJGC/odin-notes.git
git branch -M main
git push -u origin main

# 状態確認
git remote -v      # 送り先が登録されているか
git status         # 未pushかどうか
```
