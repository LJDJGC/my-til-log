- `index` は「何週目から月が変わるか」を示す。後で `weeksList.map((week, i)` と組み合わせてラベル表示に使う

**トラブルシューティング：**
- 最初は `return {index: number; label: string}[];` と型を返してしまった → 配列 `[]` を返す修正

```tsx
// weekList（完了）
const weekList = useMemo(() => {
    const list: Date[][] = [];
    for (let i = 0; i < days.length; i += 7) {
        list.push(days.slice(i, i + 7));
    }
    return list;
}, [days]);

// monthLabels（完了）
const monthLabels = useMemo(() => {
    const labels: {index: number; label: string}[] = [];
    let lastMonth = -1;
    for (let i = 0; i < weekList.length; i++) {
        const week = weekList[i];
        const month = week[6] ? week[6].getMonth() : week[0].getMonth();
        if (month !== lastMonth) {
            labels.push({ index: i, label: formatMonthLabel(week[6] || week[0]) });
            lastMonth = month;
        }
    }
    return labels;
}, [weekList]);
```

- `index` = which week number the month starts at. Used with `weeksList.map((week, i)` for label display

- Initially tried to return a type `{index: number; label: string}[]` instead of value `[]` — fixed
